## 2026-11-06T10:40:00+08:00

选区截图边框改为按背景亮度自适应，修复暗色模式下边框几乎不可见。

- **原因**：边框是「背景模糊 + brightness(0.9)」，暗色背景下可压暗的空间很小（如 #1a1a1a→#171717），视觉上消失。
- **自适应**（新文件 `src/content/screenshot-decoration.ts`，从 `image.ts` 拆出装饰管线）：采样选区外环中位色并计算 WCAG 相对亮度；`resolveBackdropStyle` 在亮度 ≤0.12 用 `brightness(1)` + 12% 白色叠加提亮，≥0.45 保持 `brightness(0.9)` 压暗，中间平滑过渡。纯黑背景乘法提亮无效，故用加性白色 lift。
- 圆角、圆角模糊边框、外圈透明、暂存区只存 A 的语义均不变；`image.ts` 保留裁剪/下载入口。
- **测试**：新增 `tests/unit/content/screenshot-decoration.test.ts`（4 例：亮度映射、暗/亮分支、单调性）；annotator 351 单测、`vue-tsc -b`、eslint 0 error、`npm run build` green、stitch e2e 5 passed/1 skipped。暗色实测边框 `#2f2f30` vs 卡片 `#0b0b0c`。
