## 一、定义

为便于理解，本协议使用如下定义：

- **“我们/维护者/贡献者”**：指 MyZ 项目的维护者与贡献者（不等同于任何第三方服务提供方）。
- **“你/用户”**：指安装或使用本扩展的个人或你所代表的组织。
- **“本扩展/扩展”**：指上述任一 MyZ 浏览器扩展及其更新版本。
- **“本地数据”**：指扩展在你的浏览器本地存储中的数据，包括但不限于标注、批注、标签、截图元数据、弹幕缓存、设置等。
- **“可选网络功能”**：指你自行启用后会产生网络请求的功能（例如自定义 AI Provider、MCP Server、社区导入、加密同步，以及与第三方网站的交互）。
- **“自定义 AI Provider”**：指你在设置中自行配置的 OpenAI 兼容接口（Base URL、API Key、Headers、Models 等）。
- **“MCP Server”**：指你在设置中自行配置的 MCP 工具服务器（URL、Headers 等），用于为模型提供 tools 能力。
- **“社区导入”**：指通过浏览器打开并抓取 X（Twitter）与 Mastodon 页面来导入内容的功能（无需官方 API）。
- **“加密同步（E2EE Sync）”**：指你自行配置 S3 兼容对象存储并使用同步密钥进行端到端加密的数据同步能力。
- **“第三方服务/第三方网站”**：指不由我们运营或控制的服务或网站（例如你配置的自定义 AI Provider、MCP Server、S3 兼容对象存储、X/Mastodon、YouTube 等）。

## 六、可选网络功能与第三方服务（重要条款）

### 6.1 自定义 AI Provider（OpenAI 兼容接口）

1. 你可以配置自定义 AI Provider（Base URL、API Key、Headers、Model 等），由浏览器直接向你配置的服务器发起请求。
2. 你理解并同意：
   - 你配置的服务器可能位于不同法域，并可能进行日志留存、内容存储、训练使用或二次处理（具体取决于该服务方政策）。

   - 自定义 AI Provider **可能消耗大量 token 并产生高额费用**；你应自行了解计费规则并对费用负责。
3. 我们不对第三方 AI 服务的可用性、准确性、输出质量、合规性、数据处理方式或收费策略作出任何保证。

### 6.2 MCP Server（外部 tools 服务）

1. 你可以配置 MCP Server 的 URL 与 Headers，由浏览器直接请求 tools 列表并在对话过程中发起工具调用。
2. 你理解并同意：
   - MCP Server 可能访问、处理或返回与你的标注/网页上下文相关的信息；
   - 该服务的安全性、合规性、日志留存与收费策略由其服务方决定；
   - 你应自行评估是否启用以及启用哪些 tools，避免不必要的信息暴露。
3. 我们不对 MCP Server 的工具输出、正确性、可用性或由其导致的任何损失承担责任。

### 6.3 社区导入（X / Mastodon）

1. 社区导入通过浏览器打开页面并抓取内容实现（无需官方 API），可能需要你在浏览器里已登录对应账号。
2. 你理解并同意：

### 6.4 MyZ 弹幕助手（YouTube 私有接口）

1. MyZ 弹幕助手可能通过 YouTube 的私有接口读取公开评论，用于本地生成弹幕展示。
2. 你理解并同意：
   - 该能力依赖于第三方平台的非公开接口，可能随时被更改、限流或阻断；
   - 若因此导致账号访问受限、视频无法播放或出现其他问题，责任由你自行承担。

### 6.5 加密同步（S3 兼容）

1. 你可以配置 S3 兼容对象存储（Endpoint、Region、Bucket、Access Key、Secret Key 等）并设置同步密钥，由浏览器直接与该存储交互。
2. 你理解并同意：
   - 同步密钥由你输入的密码派生，我们不保存你的密码；若遗忘密码，新的客户端无法解密旧数据，需要重新全量加密并同步；
   - 云端仅存储密文与必要元信息；同步实现为端到端加密（E2EE），不会向同步平台暴露明文；
   - 对象存储服务的安全性、可用性、计费与合规责任由你自行承担，我们不对第三方服务故障或争议负责。
3. 加密同步实现可公开审阅，代码位于 <https://github.com/myz-suite/sync/>。
