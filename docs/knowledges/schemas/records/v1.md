# Records Schema v1 (MyZRecord)

Version: 1.0.0

## Purpose
Defines the persisted record structure used across storage, sync payloads, and UI rendering. This schema is authoritative for the record data model.

## Shape
```
MyZRecord (object)
```

## Fields
- `schemaVersion` (string, required)
  - Fixed literal: `"1.0.0"`.
  - Schema version for the record structure.
- `id` (string, required)
  - Unique record identifier.
- `kind` (enum, required)
  - One of: `highlight`, `clip`, `bookmark`.
- `sourceType` (enum, optional)
  - One of: `web`, `pdf`, `epub`. Identifies which reader the record belongs to.
- `pdfLocator` (object, optional)
  - Locates an excerpt in a PDF: `pageNumber`, `text`, optional `occurrenceIndex`, `rects`.
- `epubLocator` (object, optional)
  - Locates a spot in an EPUB (reflow, no page numbers): `spineIndex`, optional
    `progression` (0–1), optional `textQuote` / `textPrefix` / `textSuffix`.
- `text` (string, required)
  - Primary content text. Can be empty for bookmark-like records.
- `html` (string, optional)
  - HTML content for rich highlights/clips.
- `contentType` (enum, optional)
  - One of: `text/html`, `text/markdown`, `text/plain`.
- `note` (string, optional)
  - User note attached to the record.
- `tags` (string[], optional)
  - User tags.
- `color` (string, optional)
  - Highlight color (hex string).
- `style` (enum, optional)
  - One of: `paint`, `underline`, `wavy`.
- `createdAt` (string, required)
  - ISO timestamp.
- `updatedAt` (string, required)
  - ISO timestamp.
- `sourceUrl` (string, optional)
  - Canonical source URL (normalized alias of `url`).
- `title` (string, optional)
  - Page title.
- `hostname` (string, optional)
  - Page hostname.
- `range` (object, optional)
  - Serialized selection range (start/end points with DOM path + offsets).
- `url` (string, required)
  - Primary URL identifier.
- `unreachable` (boolean, optional)
  - Derived UI status indicating page no longer reachable.

## Notes
- Unknown fields are permitted only for forward-compatibility but are not part of the v1 spec.
