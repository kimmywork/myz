# Settings Schema v1

Version: 1.0.0

## Purpose
Defines the persisted Settings payload stored in `myz::settings` (wrapped by a versioned bundle). It is the authoritative schema for configuration state.

## Storage Envelope
```
SettingsBundleV1
- schemaVersion: "1.0.0"
- data: SettingsV1
```

## SettingsV1 (top-level fields)
- `dashboardView` (enum, required): `cards` | `list`
- `colorPalette` (string[], required): palette hex colors
- `lastUsedStyle` (enum, required): `paint` | `underline` | `wavy`
- `lastUsedColor` (string, required): hex color
- `socialImport` (object, required)
  - `twitter.profileUrl` (string)
  - `mastodon.profileUrl` (string)
- `sync` (object, required)
  - `enabled` (boolean)
  - `s3.endpoint` (string)
  - `s3.region` (string)
  - `s3.bucket` (string)
  - `s3.accessKeyId` (string)
  - `s3.secretAccessKey` (string)
  - `s3.sessionToken` (string, optional)
  - `s3.prefix` (string, optional)
- `aiAssistantEnabled` (boolean, required)
- `aiProviders` (array, required)
  - `id` (string)
  - `name` (string)
  - `type` (enum): openai_compatible | openai_responses | gemini | anthropic | moonshot | qwen | ollama | vllm | llama_cpp
  - `enabled` (boolean)
  - `streamingEnabled` (boolean, optional)
  - `baseUrl` (string)
  - `apiKey` (string)
  - `headers` (string)
  - `models` (array)
    - `id` (string)
    - `model` (string)
    - `enabled` (boolean)
    - `capabilities.vision` (boolean)
    - `capabilities.imageOutput` (boolean)
    - `capabilities.toolCalling` (boolean)
    - `capabilities.reasoning` (boolean)
    - `limits.contextWindow` (number)
    - `limits.maxOutputTokens` (number)
    - `limits.maxOutputTokenParam` (enum): max_tokens | max_completion_tokens
    - `tooling.toolChoice.mode` (enum): auto | none | required | tool
    - `tooling.toolChoice.toolName` (string, optional)
    - `tooling.strict` (enum): auto | on | off
    - `tooling.parallelToolCalls` (enum): auto | on | off
    - `systemPromptInUserMessage` (boolean, optional)
  - `lastTest` (object | null)
    - `ok` (boolean)
    - `message` (string)
    - `testedAt` (string)
    - `model` (string)
- `aiAgents` (object, required)
  - `conversation` (object)
  - `insights` (object)
  - `autoHighlight` (object)
  - Shared agent fields:
    - `target` (object | null): { providerId, modelId }
    - `temperature` (number)
    - `compressImages` (boolean, optional)
    - `superpowerMode` (boolean, optional)
    - `multimodalTarget` (object | null, optional): { providerId, modelId }
    - `contextCompressionThreshold` (number, optional)
    - `maxHighlights` (number, optional)
  - `autoHighlight.categoryStyles` (object, optional)
    - `conceptual` / `structural` / `behavioural` => { style, color }
- `aiMcpServers` (array, required)
  - `id` (string)
  - `name` (string)
  - `enabled` (boolean)
  - `url` (string)
  - `headers` (object, optional)
  - `lastTest` (object | null, optional)
- `aiLocalTools` (object, required)
  - `enabledToolNames` (string[])
  - `mode` (enum): manual | auto
  - `autoSelectorTarget` (object | null): { providerId, modelId }
- `aiSkills` (object, required)
  - `mode` (enum): manual | auto
  - `autoSelectorTarget` (object | null): { providerId, modelId }
- `vectorSearch` (object, required)
  - `enabled` (boolean)
  - `target` (object | null): { providerId, modelId }
  - `lastTest` (object | null)
    - `ok`, `message`, `testedAt`, `providerId`, `modelId`, `model`
  - `matchThreshold` (number)

## Notes
- `SettingsBundleV1` is the persisted wrapper; only `data` is used at runtime.
- All settings are normalized on read/write to enforce defaults and valid ranges.
