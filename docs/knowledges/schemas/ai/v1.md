# AI Schema v1

Version: 1.0.0

## Purpose
Defines the persisted AI conversation and message structures for sidepanel/history storage and sync.

## ConversationInfoV1 (storage)
- `schemaVersion` (string, required): literal `"1.0.0"`
- `id` (string, required)
- `title` (string, required)
- `url` (string, required)
- `createdAt` (string, required)
- `updatedAt` (string, required)
- `metadata` (object, optional)
- `sendContextEnabled` (boolean, optional)

## MessageV1 (storage)
- `schemaVersion` (string, required): literal `"1.0.0"`
- `id` (string, required)
- `conversationId` (string | null, optional)
- `role` (enum, required): user | assistant | tool | system
- `content` (string, required)
- `timestamp` (string, required)
- `reasoning_content` (string, optional)
- `tool_calls` (array, optional)
  - `id` (string)
  - `type` (literal): function
  - `function.name` (string)
  - `function.arguments` (string)
  - `index` / `thought_signature` (optional)
- `tool_call_id` (string, optional)
- `metadata` (object, optional)

## Notes
- `schemaVersion` is required at rest; runtime message objects may be normalized before persistence.
- Additional tool-call properties are permitted for forward compatibility but are not part of the v1 core spec.
