# Sync Protocol v1 (E2EE)

Protocol Version: 1.0.0

## Scope
Defines the versioned payloads exchanged by the E2EE sync engine, including record payloads, manifest data, and encrypted chunk envelopes.

## SyncRecordPayloadV1
- `protocolVersion` (string, required): literal `"1.0.0"`
- `recordId` (string, required)
- `type` (enum, required): `highlight` | `ai-conversation`
- `updatedAt` (string, required, ISO timestamp)
- `data` (object, required): encrypted payload content (MyZRecord or AI conversation bundle)

## ManifestDataV1
- `protocolVersion` (string, required): literal `"1.0.0"`
- `version` (number, required): manifest monotonic version counter
- `createdAt` (string, required)
- `clientId` (string, required)
- `baseVersion` (number, required)
- `epoch` (number, required)
- `recordsIndex` (map)
  - `recordId` => { `chunkId`, `updatedAt`, `recordHash` }
- `chunksIndex` (map)
  - `chunkId` => { `hash`, `size`, `nonce` }
- `chainHeads` (map)
  - `recordId` => { `keyId`, `recordHash`, `updatedAt` }

## ChunkEnvelopeV1
- `protocolVersion` (string, required): literal `"1.0.0"`
- `recordId` (string, required)
- `updatedAt` (string, required)
- `prevHash` (string, required)
- `keyId` (string, required)
- `recordCipher` (string, required)
- `recordNonce` (string, required)

## LockPayloadV1
- `clientId` (string, required)
- `leaseExpiresAt` (string, required)
- `issuedAt` (string, required)
- `signature` (string, required)

## Notes
- `protocolVersion` is independent from `manifest.version` (which is a monotonic counter).
- Unsupported `protocolVersion` values must abort sync with an explicit error.
